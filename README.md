# 🧠 Reusable AI Prompt Library

> Biblioteca centralizada de prompts estruturados, modulares e reutilizáveis, projetados com **placeholders customizáveis** para adaptação rápida em diferentes áreas e fluxos de trabalho.

---

### 🎯 Propósito do Repositório

Este repositório reúne templates de prompts desenvolvidos com foco em **Engenharia de Prompt** aplicada. Em vez de instruções engessadas para um único cenário, cada prompt desta biblioteca funciona como um molde versátil: basta substituir os `[placeholders]` indicados para adaptar a instrução a diferentes contextos, profissões ou objetivos.

### 🛠️ Padrão de Estrutura Aplicado

Para garantir previsibilidade e qualidade nas respostas da IA, os templates seguem uma arquitetura padronizada:

* **Definição de Papel (Persona):** Contextualização clara de domínio e tom de voz esperado.
* **Placeholders Adaptáveis (`[VARIÁVEL]`):** Campos delimitados para inserção rápida do contexto, público-alvo ou dados específicos do usuário.
* **Regras e Restrições:** Delimitação explícita do que o modelo *não* deve fazer para evitar alucinações ou fuga de escopo.
* **Formato de Saída:** Padronização visual das respostas (Markdown, tabelas, listas estruturadas ou blocos de código).
